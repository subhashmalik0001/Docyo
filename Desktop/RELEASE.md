# Docyo Desktop 0.2.0

Windows and Linux desktop release for Docyo featuring the **Interactive Radial Converter Wheel**, **Floating Companion Wheel**, and the **3D Grape Penguin Vinyl Toy Avatar**.

- Windows 10/11 x64 portable ZIP; Linux x64 Ubuntu 24.04 / glibc 2.39+ tar.gz.
- **Radial Converter Wheel:** Fast one-drop conversion onto format wedges (PNG, JPEG, WEBP, PDF, Merge PDFs, MP4, MP3, Extract text).
- **Floating Companion Wheel:** Frameless, transparent desktop floating companion for dragging and dropping files anywhere.
- **3D Avatar Studio:** Real-time 360° mouse-tracking 3D Grape Penguin vinyl toy studio.
- Multi-file drag into the app, image conversion/resize/rotation, image to PDF, PDF merge/split/text, SRT/VTT subtitles, and SHA-256 checksums.
- Optional audio/video transcoding with your own trusted FFmpeg installation.
- Originals retained; exclusive collision-proof output naming; isolated workers with cancellation and deadlines.
- Full application source, dependency versions, and license notices included in each package.

Extract the full archive, then run `Docyo.exe` (Windows) or `Docyo` (Linux). Keep the `_internal` folder alongside the executable. Verify SHA-256 against the companion checksum file.

Documentation and details: https://github.com/subhashmalik0001/Docyo/blob/main/Desktop/README.md  
macOS users: use the native macOS edition.
